Тренировка

Пять учебных вопросов. Ответ показан сразу — для самопроверки.

1. В населённом пункте скорость по умолчанию:

  1. 40 км/ч
  2. 60 км/ч
  3. 90 км/ч

Ответ: 2 — если знаками не установлено иное.

2. Знак «Въезд запрещён» означает:

  1. Остановку нельзя
  2. Въезд с этой стороны запрещён
  3. Стоянку нельзя

Ответ: 2.

3. На равнозначном перекрёстке без знаков приоритета:

  1. Едет тот, кто справа
  2. Уступает тот, у кого помеха справа
  3. Всегда уступает грузовой

Ответ: 2.

4. Обгон на пешеходном переходе:

  1. Разрешён ночью
  2. Запрещён
  3. Разрешён при отсутствии людей

Ответ: 2 — по общим правилам запрещён.

5. Аварийная сигнализация включается:

  1. Только на трассе
  2. При ДТП и в иных предусмотренных случаях
  3. Только по требованию инспектора

Ответ: 2.

Это учебные формулировки. Перед экзаменом сверяйтесь с актуальными официальными материалами.
